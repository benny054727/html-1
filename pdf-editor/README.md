# עורך MY PDF

עורך PDF בעברית שרץ כולו בדפדפן. הקבצים לא נשלחים לשום שרת.
האתר: https://benny054727.github.io/html-1/pdf-editor/

## מבנה הקוד

| תיקייה / קובץ | מה יש בו |
|---|---|
| `index.html`, `app.css` | המבנה והעיצוב של האתר |
| `src/` | הקוד, מחולק לפי נושאים (ראו למטה) |
| `app.js` | **נבנה אוטומטית** מ־`src/`. לא עורכים אותו ישירות |
| `vendor/` | ספריות וגופנים (pdf.js, pdf-lib, fontkit וגופנים בעברית) |
| `sw.js`, `manifest.webmanifest`, `icons/` | האפליקציה: התקנה ועבודה בלי אינטרנט |
| `tests/run.mjs` | בדיקות אוטומטיות |
| `tools/build.mjs` | בונה את `app.js` מהקבצים ב־`src/` |

הקבצים ב־`src/` לפי הסדר: מצב ושמירת ביטולים (`01-core`), ציור טקסט וחותמות (`02`), טפסים (`03`),
טעינת קבצים (`04`), רשת העמודים (`05`), ייצוא, טקסט אמיתי והקטנה (`06`), העורך (`07`), אותיות/מילים/שורות (`08`),
הקלדה על הדף (`09`), סרגל העיצוב (`10`), חתימות/תמונות/צורות (`11`), קווי עזר, העתקה וחיתוך (`12`),
הוספה וכלים (`13`), סיסמאות (`14`), סיור היכרות (`15`), שמירה במכשיר (`16`), התקנה ואופליין (`17`).

## עבודה על הקוד

```bash
cd pdf-editor
npm install                 # פעם אחת
npx playwright install chromium   # פעם אחת, דפדפן לבדיקות
npm run build               # אחרי כל שינוי ב־src/
npm test                    # כל הבדיקות (כחצי דקה)
node tests/run.mjs forms    # רק בדיקות שבשמן מופיע "forms"
```

אחרי שינוי ב־`app.js` או `app.css` מעלים את המספר `?v=` ב־`index.html` ואת `VERSION` ב־`sw.js`,
כדי שהטלפונים יטענו את הגרסה החדשה.

הבדיקות רצות גם אוטומטית ב־GitHub על כל בקשת מיזוג.
